# Version 1.0.0 — Initial public release

The first public release contains:

- An eight-page human build guide in PDF and editable DOCX formats
- A technical AI companion guide covering Claude Desktop and ChatGPT/OpenAI
  control paths
- A privacy-scrubbed Python reference implementation for one Hue light
- Fixed companion identities, local physical arming, per-actor run accounting,
  exclusive execution, emergency stop, state restoration, and sanitized logs
- Generic launcher templates and a non-destructive Claude Desktop installer
- Automated tests for Morse timing, restoration, run isolation, stop behavior,
  exact local HTTPS addressing, and preservation of existing Claude MCP servers

## Live validation

The programmed pattern contains 31 timing units and lasts 15.5 seconds at the
default half-second unit. A recorded Claude Desktop rehearsal completed in
18.466 seconds wall-clock, consumed exactly one fixed actor run, restored the
light, and ended disarmed.

## Privacy

This release contains no live Hue application key, Bridge address, Bridge ID,
light resource ID, household account identifier, private computer path, or
runtime log.
